# Premium redesign — first pass

Контекст: бренд-позиционирование "премиальный ИИ-помощник для дома" —
единый дизайн-код вместо разрозненных экранов.

## Что добавлено в этом проходе

### `lib/core/theme/app_gradients.dart`
Единая палитра градиентов вместо плоских цветов:
- `AppGradients.primary` — герои, основные CTA
- `AppGradients.success / warning / danger` — динамические статусы
  (🟢 выполнено · 🟡 в процессе · 🔴 срочно)
- `AppGradients.splash` — фон сплэша (уже применено)
- `AppGradients.forStatus(AppStatusTone)` — единая точка выбора цвета статуса

### `lib/core/widgets/cards/glass_card.dart`
`GlassCard` — glassmorphism-карточка (blur + полупрозрачность + бордер),
опционально с градиентной подложкой. Не заменяет `AppCard` — используется
точечно для hero-блоков, приветствия, поднятых панелей.

### `lib/core/widgets/badges/status_badge.dart`
`StatusBadge` / `StatusBadge.fromStatusKey(status)` — единый бейдж статуса
заказа с автоматическим градиентом и текстом. Используй везде вместо
кастомных Container с ручным цветом, чтобы статусы выглядели одинаково
на всех экранах (лента заказов, карточка мастера, детали заказа).

### `lib/core/widgets/feedback/skeleton_loader.dart`
`SkeletonShimmer` + `SkeletonBox` + готовый `SkeletonListCard` —
скелетон-заглушки вместо спиннеров. Показывать во время загрузки списков
(мастера, заказы, категории), чтобы приложение казалось быстрее.

### `lib/core/widgets/buttons/animated_press.dart`
`AnimatedPress` — обёртка с лёгким bounce (scale) + тактильный отклик на
любой тап. Замена `GestureDetector(onTap: ...)` там, где нужна
"живая" микро-анимация (примечание: `Material`/`InkWell` уже даёт ripple
из коробки — не дублировать оба эффекта на одном элементе).

### `lib/core/widgets/navigation/app_bottom_sheet.dart`
`AppBottomSheet.show(context, child: ...)` — единый bottom sheet
(закруглённые углы, drag-handle, тактильный отклик при открытии) вместо
пуша новой страницы для коротких действий (выбор мастера, подтверждение,
слот времени).

### `lib/core/utils/app_haptics.dart`
`AppHaptics.tap / success / celebrate / error` — тактильная отдача в одном
месте: `tap()` на выборе, `success()` на принятии заказа, `celebrate()` на
оплате/завершении работы, `error()` на отмене/ошибке.

### Зависимости (`pubspec.yaml`)
- `lottie: ^3.3.1` — для анимации "✅ Заказ принят" и подобных состояний
  (сами Lottie-файлы ещё не добавлены — нужно выбрать/купить анимации и
  положить в `assets/lottie/`).
- `cached_network_image: ^3.4.1` — кеширование фото мастеров/категорий
  с диска, лениво по мере попадания во вьюпорт.

### Экраны
- **Splash** (`features/splash/presentation/splash_screen.dart`) — фон
  переведён с плоского `#57B55E` на `AppGradients.splash` (живой градиент),
  остальная анимация (иконки, staggered fade, dots) не тронута — она уже
  была сделана качественно.
